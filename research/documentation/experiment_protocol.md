
# Brain MRI Analysis Using LLaVA
## Experiment Protocol — Baseline Study

### 1. Research Objective

To investigate whether radiology-guided prompting can improve the structure, clarity, and completeness of brain MRI explanations generated by a multimodal vision-language model.

### 2. Model

- Model: LLaVA
- Runtime: Ollama
- Backend: FastAPI
- Inference environment: Local CPU / integrated graphics
- Temperature: 0.1
- Maximum generated tokens: 350

### 3. Dataset

- Dataset: BraTS 2021
- Sample: BraTS2021_00495
- Input modality: T1CE
- Input image: T1CE_slice.png
- Image dimensions: 336 × 336
- Reference segmentation mask: Available separately

### 4. Prompt Configurations

Four prompt configurations are evaluated:

1. Generic
2. Tumor-focused
3. Radiology-guided
4. Safety-aware

The same MRI input is used across all four configurations.

### 5. Output Structure

Each generated report contains seven fields:

1. Findings
2. Location
3. Lesion characteristics
4. Edema
5. Mass effect
6. Interpretation
7. Uncertainty

### 6. Evaluation

The current backend calculates:

- Total fields
- Assessable fields
- Non-assessable fields
- Assessable Field Rate (%)
- Whether uncertainty is provided

Assessable Field Rate measures how many report fields contain assessable content. It does not establish factual correctness, clinical accuracy, or diagnostic performance.

### 7. Experimental Procedure

1. Select the processed T1CE MRI slice.
2. Submit the image to the backend.
3. Generate reports using the four prompt configurations.
4. Record inference time for each prompt.
5. Preserve the complete raw JSON responses.
6. Compare the structure and content of generated reports.
7. Document inconsistencies, unsupported claims, and limitations.

### 8. Research Limitations

- Only one BraTS sample and one MRI slice are used in this initial experiment.
- LLaVA outputs are not clinically validated.
- Generated explanations may contain hallucinations.
- Assessable Field Rate is not an accuracy metric.
- Text-based reports do not provide pixel-level segmentation performance.
- Results from one sample cannot establish generalisability.
